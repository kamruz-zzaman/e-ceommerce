# Product image attribution

These 51 photographs illustrate synthetic assessment products. They are not
supplier photographs of the exact fictional configurations, and do not imply
endorsement by photographers, pictured people, manufacturers, or Wikimedia.
Props, food, plants, and accessories visible in photographs are not included.
Each family uses one representative photograph across compatible sizes or pack
quantities. The single-tote and two-bag shopping-set families intentionally share `tote.jpg`;
the photograph represents one bag in the pair.
Galleries contain one image, without duplicated views.

All files are local in `public/images/products/`; no image host is contacted
at runtime. Sources are Wikimedia Commons file pages linked below. Images were
resized (longest edge at most 960 px) and re-encoded as JPEG, with EXIF orientation
applied. No creative retouching or new branding was added. The local versions
retain the listed source licenses, including share-alike terms where applicable.
License links and source pages contain the full terms and copyright declarations.
Author qualifiers such as "assumed" are reproduced from the original source
metadata, not inferred by this project. Missing author metadata is stated explicitly.
Where a source offers multiple licenses, the table identifies the Creative Commons
option used for these local copies.
